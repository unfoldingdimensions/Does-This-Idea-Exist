## 2026-08-24 - Add ARIA labels to external links\n**Learning:** While `ExternalLink` and `FolderGit2` buttons had visible text ('Website', 'Code'), screen readers were not notified they open in a new tab. Providing specific `aria-label` attributes that name the startup and note the '(opens in a new tab)' behavior is a high-value accessibility win that requires zero visual changes.\n**Action:** Whenever a link has `target="_blank"`, ensure there is a screen-reader-friendly warning (e.g., via `aria-label`) about the context switch, and provide descriptive link text if the visible text is too generic.
